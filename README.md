# MNE-M/EEG_Analysis
This Repo is for the work-through of M/EEG analysis with MNE Python following [Richard Höchenberger's workshop](https://www.youtube.com/watch?v=t-twhNqgfSY&t=423s).


# Setup
Unlike the *conda virtual environment setup* [Richard Höchenberger mentioned in this workshop](https://www.youtube.com/watch?v=t-twhNqgfSY&t=423s), we will be using *python virtual environment (venv)*:
```bash
# 1. Create the venv
python3 -m venv .venv

# 2. Activate the venv
source .venv/bin/activate

# 3. Install dependencies
pip install -r reqs.txt
```
